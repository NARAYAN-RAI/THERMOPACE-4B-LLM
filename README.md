OverviewDeploying Large Language Models (LLMs) on entry-level cloud Graphics Processing Units (GPUs) relies heavily on 4-bit weight quantization—such as 4-Bit NormalFloat (NF4)—to fit models inside strict Video Random Access Memory (VRAM) budgets. However, existing thermal-aware schedulers and hardware power-capping utilities (nvidia-smi -pl) require root administrator privileges (CAP_SYS_ADMIN) that are locked in virtualized cloud environments and serverless notebooks.This repository contains the complete, reproducible experimental telemetry suite and runtime implementation for ThermoPace-4B:Phase I Empirical Characterization (phase1_scaling_benchmark.py): Profiles Qwen/Qwen2.5-3B-Instruct quantized to 4-bit NF4 on an NVIDIA Tesla T4 GPU across six doubling output horizons (64, 128, 256, 512, 1024, 2048 tokens) using 10 Hz NVML hardware polling and CodeCarbon whole-node (GPU + Host RAM + CPU) carbon accounting.Phase II Zero-Privilege Runtime (phase2_thermopace4b_benchmark.py): Implements ThermoPace-4B inside PyTorch's native LogitsProcessor and StoppingCriteria hooks—requiring zero CUDA kernel rewrites and zero root privileges—combining:Module 1 (RC-PID Thermodynamic Token Pacer): Stride-16 NVML thermal polling that injects bounded micro-sleep duty cycles ($\Delta\tau_k \le 45\text{ ms}$) above $T_{\text{set}} = 58\,^\circ\text{C}$ to halt GDDR6 memory reads and drop board power toward idle (~13 W).Module 2 (GreenKV Logit-Entropy Tracker): Computes next-token Shannon entropy $H_k$ directly from output vocabulary logits to rank semantic anchors without inspecting internal attention matrices, keeping PyTorch's fused Scaled Dot-Product Attention (SDPA / FlashAttention-2) 100% active.Module 3 (Confidence-Gated Speculative Self-Exit): Tracks smoothed top-1 certainty ($\bar{p}_{\max}$) and halts generation cleanly at clause boundaries (. or \n) once $\bar{p}_{\max} \ge 0.90$ after $L_{\min} = 512$ tokens.Publication Figure & Regression Pipeline (generate_paper_figures.py): Computes Ordinary Least Squares (OLS) thermal regressions and exports 300 DPI multi-panel figures directly from the CSV telemetry logs.2. Hardware & Software PrerequisitesHardware: 1x NVIDIA GPU with CUDA support (tested on NVIDIA Tesla T4, 16 GB GDDR6 VRAM, 70 W nominal TDP; runs 100% free on Google Colaboratory T4 GPU runtime).Privileges: Standard unprivileged user-space account (no sudo or root access required).Software: Python 3.10+, CUDA-enabled PyTorch, and the libraries listed in requirements.txt.4.
